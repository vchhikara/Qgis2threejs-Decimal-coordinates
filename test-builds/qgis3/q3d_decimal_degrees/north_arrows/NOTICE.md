# North-arrow artwork

The files `NorthArrow_01.svg` through `NorthArrow_11.svg` were copied from the QGIS 3.44.12 installation, under `apps/qgis-ltr/svg/arrows`. Their Git blob hashes match the QGIS project's `release-3_44` sources at <https://github.com/qgis/QGIS/tree/release-3_44/images/svg/arrows>.

QGIS states that the project is distributed under the GNU General Public License, version 2 or any later version. `COPYING-QGIS` contains its GPL version 2 license text. These SVGs are unmodified in the plugin package; the plugin substitutes browser-compatible values for QGIS colour parameters when displaying or exporting them.

Before distributing this package, review the provenance and licensing of each SVG in the upstream repository, including any notices and third-party exceptions.
