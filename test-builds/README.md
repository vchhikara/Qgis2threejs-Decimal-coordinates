# Test builds

These builds are for testing and are not publication-ready releases. The released version 0.2.2 remains at the repository root.

- `qgis3/`: version 0.2.3 source and verification scripts.
- `qgis4/`: version 0.2.4 source.
- The two `*_TEST.zip` files are installable packages for the matching QGIS major version.
- See [TEST_STATUS.md](TEST_STATUS.md) for completed checks and outstanding limitations.

Use the matching ZIP through QGIS Plugin Manager. Both editions use the same plugin identifier and are intended for their corresponding QGIS versions.
